# بوت التواصل Telegram (مع دعم الرد بالذكاء الاصطناعي 🤖)

نسخة محدثة من بوت التواصل باستخدام `python-telegram-bot` تدعم الرد الذكي التلقائي.

## المتغيرات المطلوبة والبيئة

```bash
BOT_TOKEN=توكن_البوت
OWNER_ID=معرف_المالك

# اختياري للذكاء الاصطناعي (يمكن أيضاً ضبطه وتغييره من لوحة التحكم داخل البوت مباشرة):
AI_API_KEY=مفتاح_الذكاء_الاصطناعي
# أو OPENAI_API_KEY=sk-...
```

## ميزة الرد بالذكاء الاصطناعي الجديدة 🤖

1. **زر مخصص في لوحة التحكم:**
   - يظهر زر `🤖 الرد بالذكاء الاصطناعي — [مفعّل / معطّل]` في لوحة تحكم المالك.
2. **التعليمات المكتوبة (System Prompt):**
   - إمكانية قراءة وتعديل التعليمات والتوجيهات الموجهة للذكاء الاصطناعي في أي وقت مباشرة عبر البوت.
3. **مفتاح الذكاء الاصطناعي (API Key):**
   - جاهز للعمل مع OpenAI أو أي مزود متوافق (Groq, DeepSeek, OpenRouter).
   - يمكن إدخال أو تعديل المفتاح مباشرة من لوحة التحكم بزر واحد، أو تحديده كمتغير بيئة `AI_API_KEY`.
4. **تغيير الموديل:**
   - الموديل الافتراضي هو `gpt-4o-mini` ويمكن تغييره لأي موديل آخر (مثل `gpt-4o`, `deepseek-chat`).
5. **سير العمل عند التفعيل:**
   - عندما يرسل المستخدم رسالة، يرد الذكاء الاصطناعي عليه فوراً وفق التعليمات المحددة.
   - يتم تحويل رسالة المستخدم للمالك مع عرض رد الذكاء الاصطناعي نفسه، وزر لحذفه، وإمكانية الرد يدوياً عبر Reply.
   - يدعم الرد تنسيق Telegram HTML مثل العريض والمائل والتسطير والشطب والكود والاقتباسات والروابط.

## الحظر بسبب ومدة ⏱️

- استخدم الأمر بالرد على رسالة العضو:

  ```text
  /ban سبب الحظر هنا
  ```

- أو باستخدام المعرف:

  ```text
  /ban USER_ID سبب الحظر هنا
  ```

- بعد إرسال الأمر تظهر خيارات: ساعة، 6 ساعات، 12 ساعة، يوم، 3 أيام، 7 أيام، 14 يوم، 30 يوم، أو حظر دائم.
- يصل العضو إشعار بصيغة: **تم حظرك بسبب:** ثم يظهر السبب بخط عادي.
- يُحفظ السبب والمدة ووقت الانتهاء في `banned.json` ويظهر في قائمة المحظورين وسجل المستخدم.
- الحظر المؤقت ينتهي تلقائياً، أما الحظر الدائم فيستمر حتى استخدام `/unban`.
