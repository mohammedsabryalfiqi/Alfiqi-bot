# 🚀 منصة استضافة بوتات تلجرام — Alfiqi Bot Hosting Platform

منصة متكاملة (Bot-as-a-Service) لاستضافة وإدارة **بوتات تلجرام متعددة** من خلال بوت رئيسي واحد،
مع دعم نوعين من القوالب الجاهزة بميزات جبارة — كل قالب يعمل باستقلال تام ببيانات خاصة بصاحبه.

| القالب | الوصف |
|---|---|
| 📩 **بوت تواصل** | بوت رسائل خاص بين الأعضاء وصاحبه: لوحة تحكم إنلاين، ترحيب/أزرار ملونة، رد سريع، رد تلقائي بكلمات مفتاحية، **رد بالذكاء الاصطناعي** (OpenAI/Groq/OpenRouter/DeepSeek)، حظر/كتم/تأجيل، بث للجميع، حماية محتوى، وإيموجي بريميوم. |
| 🛡️ **بوت حماية مجموعات** | مستوحى من GroupHelp: ترحيب/وداع مع **كابتشا زر**، قواعد، حظر/طرد/كتم مؤقت، **نظام تحذيرات (Warns)**، **Anti-Flood**, **Anti-Link**، **كلمات محظورة** (مع فلتر إساءات عربية)، **Night Mode**, **Slow Mode**، منع وسائط، منع رسائل القنوات، منع إضافة بوتات، بلاغات للأدمن، أوامر ملاحظات، تسجيل إجراءات الأدمن في مجموعة سجل، وتنظيف رسائل (purge). |

المشروع مبني من الصفر على **python-telegram-bot v22.8+ (Bot API 7.x)**، وكل بوت مُضاف يعمل كـ `Application` مستقل داخل نفس العملية (polling موازٍ).

## ✨ الميزات الكاملة

### 🧠 بوت المنصة (الرئيسي)
- إضافة بوت جديد بمجرد إرسال **التوكن** اللي تصنعه من [@BotFather](https://t.me/BotFather)
- التحقق التلقائي من صلاحية التوكن ومنع التكرار
- اختيار النوع بضغطة زر (تواصل / حماية)
- تشغيل / إيقاف / إعادة تشغيل / حذف لكل بوت
- زر **💬 فتح البوت** مباشرة من اللوحة
- عرض حالة البوت (🟢 شغّال/⚪ متوقف/🔴 خطأ) + اسم المستخدم + مدة التشغيل + عدد الرسائل
- **تشغيل تلقائي** للبوتات التي كانت شغّالة بعد إعادة تشغيل/نشر جديد
- **نظام مدراء** (أدمنز) بصلاحيات إنشاء بوتات
- **لوحة أدمن** تعرض كل البوتات المستضافة + إحصائيات
- أمر `/broadcast` لبث رسالة من المالك للمدراء
- **إشعار فوري** لصاحب البوت المستضاف عند توقف بوت بخطأ
- قاعدة بيانات **SQLite** + مجلد بيانات مستقل لكل بوت
- إشعار بدء التشغيل للمالك
- معالج أخطاء يرسل تقرير الخطأ للمالك فوراً

### 📩 بوت التواصل (كل نسخة مستقلة لصاحبها)
- ترحيب مخصص مع `{user_link}` + أزرار ملونة (primary/success/danger)
- دعم **إيموجي بريميوم** في النصوص والأزرار بصيغة `{emoji_id}`
- تحويل كامل لرسائل الأعضاء (نص/صور/فيديو/ملفات/ستيكر/صوت...) لصاحب البوت
- **رد ثنائي الاتجاه**: Reply على الرسالة المحوّلة يصل للعضو كرد على رسالته
- **الرد السريع** — رسالة ثابتة فورية لأي رسالة
- **الرد التلقائي** بكلمات مفتاحية (تُكتشف وحدها ضمن الجملة أو في الكابشن)
- **الرد بالذكاء الاصطناعي** مع:
  - System Prompt مخصص
  - API Key قابل للتغيير من اللوحة
  - اختيار الموديل
  - إرسال آمن بـ Telegram HTML مع fallback
  - إشعار للمالك بالرد المرسل + زر استرداد
- **الحظر** (دائم حالياً، قابلاً للتمدد بسهولة) و**فك الحظر** بأوامر مباشرة
- **لوحة تحكم إنلاين** كاملة من داخل الخاص
- **البث للجميع** (نسخ أي رسالة/وسيط لكل المستخدمين)
- **حماية المحتوى** (منع إعادة التوجيه Forward Protection)
- عرض المستخدمين والمحظورين
- استرداد (حذف) أي رد من عند العضو
- **منع إضافة البوت لمجموعات غريبة** ما لم يكن صاحبه موجوداً فيها

### 🛡️ بوت الحماية (كل نسخة مستقلة)
- **ترحيب بالأعضاء الجدد** + وسائط (صورة) + أزرار مخصصة
- **رسالة وداع**
- **كابتشا بسيط**: زر «✅ أنا لست بوت» + تقييد كتابي مؤقت + طرد/حظر تلقائي بعد المهلة
- `/rules` و `/setrules` للقواعد
- **أوامر الأدمن**:
  - `/ban` / `/unban` — حظر/فك حظر (مع سبب)
  - `/kick` — طرد
  - `/mute [دقائق]` و `/tmute` — كتم مؤقت أو دائم
  - `/unmute` — فك كتم
  - `/warn سبب` — تحذير (بعد عدد N يُنفَّذ إجراء تلقائي: ban/kick/mute)
  - `/unwarn` و `/warns`
  - `/del` — حذف رسالة
  - `/pin` — تثبيت
  - `/purge عدد` — حذف مجموعة رسائل
- **Anti-Flood**: كتم/طرد/حظر لمن يتجاوز حد رسائل في ثوانٍ معدودة
- **Anti-Link**: حذف تلقائي لروابط الويب ودعوات تلجرام، مع خيار السماح بروابط t.me
- **كلمات محظورة** + فلتر إساءات عربية شائعة (قابل للإيقاف)
- **منع وسائط** اختياري: ستيكر/مستندات/فيديو/صور/صوت/ملاحظات صوتية/جهات اتصال/مواقع/استفتاءات
- **منع إضافة بوتات** من غير الأدمن (طرد تلقائي)
- **منع أوامر البوتات** (/cmd)
- **منع النشر كقناة**
- **حد أقصى لطول الرسالة**
- **Slow Mode** (فترة بين رسائل كل عضو)
- **Night Mode** (ساعات محددة يُكتم فيها الجميع ماعدا الأدمن)
- **/id** لمعرفة آيدي العضو/المجموعة
- **/report** رداً على رسالة → يبلّغ جميع الأدمن خاصاً مع رابط الرسالة
- **نظام ملاحظات**: `/save`، `/notes`، `/note_<name>`، `/clear`
- تسجيل إجراءات الأدمن في **مجموعة سجل** (log group)
- كاش أدمن لعدم استنزاك الاستدعاءات
- حماية من تنفيذ الأوامر على أدمن آخر

## 🚀 التشغيل

### متغيرات البيئة
```bash
export BOT_TOKEN="توكن بوت المنصة (الرئيسي) — تصنعه من @BotFather"
export OWNER_ID="آيدي حسابك على تلجرام"
```

### التنصيب والتشغيل
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

### طريقة الاستخدام
1. افتح بوت المنصة الخاص بك وابعت `/start`.
2. اضغط **«➕ إضافة بوت جديد»** وأرسل توكن البوت.
3. اختر قالب البوت (📩 تواصل / 🛡️ حماية).
4. اضغط **«▶️ تشغيل»** من لوحة البوت.
5. البوت جاهز — اضغط **«💬 فتح البوت»** للبدء.

- لبوت التواصل: اذهب للبوت وابعت `/panel` للوحة تحكمه.
- لبوت الحماية: أضف البوت لمجموعتك وارفعه **أدمن** بصلاحيات (حذف رسائل + حظر + كتم + تثبيت).

### أوامر المالك (في بوت المنصة)
| الأمر | الوصف |
|---|---|
| `/start` | القائمة الرئيسية |
| `/addadmin USER_ID` | إضافة مدير يمكنه إنشاء بوتات |
| `/deladmin USER_ID` | إزالة مدير |
| `/stats` | إحصائيات المنصة |
| `/broadcast` | بث رسالة لجميع المدراء |

## 🗂️ هيكل المشروع

```
Alfiqi-bot/
├── main.py                       # نقطة الدخول
├── bot-3.py                      # (محفوظ للأرشيف) — البوت القديم
├── requirements.txt              # python-telegram-bot[job-queue]>=22.8
├── railway.toml                  # جاهز لـ Railway
├── .gitignore
└── hostbot/
    ├── __init__.py
    ├── main.py                   # البوت الرئيسي (المنصة / لوحة التحكم)
    ├── storage.py                # قاعدة SQLite + ملفات JSON
    ├── manager.py                # مدير تشغيل/إيقاف البوتات المستضافة
    └── templates/
        ├── __init__.py
        ├── _common.py            # دوال مشتركة بين القوالب
        ├── contact_bot.py        # 📩 قالب بوت التواصل
        └── protection_bot.py     # 🛡️ قالب بوت حماية المجموعات
```

البيانات تُحفظ تلقائياً في `hostbot/data/`:
- `hosting.db` — سجل البوتات والمدراء
- `bots/<id>/` — مجلد كل بوت مستضاف (إعداداته، مستخدموه، سجلاته)

## 🛡️ الأمان والمتانة

- كل بوت معزول ببياناته الخاصة ولا يختلط بغيره
- التحقق من صلاحية التوكن قبل الحفظ مع رسالة خطأ واضحة
- لا يمكن لغير المالك/المدراء رؤية أو تشغيل بوتات غيرهم
- بوت التواصل يرفض إضافته لمجموعات غريبة
- بوت الحماية يتحقق من رتبة الأدمن قبل أي أمر، ويمنع تنفيذ الأوامر على الأدمن
- معالج أخطاء شامل في التطبيق الرئيسي يرسل تفاصيل الخطأ للمالك
- تشغيل البوتات في مهام asyncio منفصلة — توقف أحدها لا يؤثر على الباقين
- تنظيف الموارد عند الإيقاف (`post_shutdown`)
- كاش لمدراء المجموعة لتفادي استهلاك الـ rate limits
- قاعدة بيانات SQLite مع `journal_mode=WAL` لأداء وثبات أعلى
